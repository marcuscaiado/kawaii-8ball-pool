# 🎱 Kawaii 8-Ball Pool

The cutest 8-ball pool game ever made! A super kawaii 2D pool game with adorable faces on every ball, sparkle effects, and full 2-player rules.

![Vite](https://img.shields.io/badge/Vite-646CFF?style=flat&logo=vite&logoColor=white)
![Canvas](https://img.shields.io/badge/Canvas_2D-E34F26?style=flat&logo=html5&logoColor=white)

## ✨ Features

- 🎱 **Kawaii Faces** — Every ball has a unique cute face (round eyes, sparkle eyes, wink, cat mouth, tongue, etc.)
- 😎 **8-Ball wears sunglasses** because it's cool
- 😊 **Blush cheeks** on every single ball
- 💖 **Heart particles** burst when a ball is pocketed
- ✨ **Sparkle particles** on every collision
- 🫧 **Squish animation** — balls squish adorably on impact
- 👥 **2-Player Mode** — Full 8-ball rules (solids vs stripes)
- 🏆 **Win Detection** — Sink the 8-ball last to win
- 🔄 **Play Again** button
- 📱 Touch support

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.

## 🎮 How to Play

1. Click and drag on the **white cue ball** to aim
2. Pull back to set power (shown in the power bar)
3. Release to shoot!
4. Pocket your balls (solids or stripes) then sink the 8-ball to win

## 🛠️ Tech Stack

- **Vite** — Fast build tool
- **HTML5 Canvas** — 2D rendering
- **Custom Physics** — Circle-circle and circle-wall collision engine
