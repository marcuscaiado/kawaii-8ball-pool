The cutest 8-ball pool game ever made! A super kawaii 2D pool game with adorable faces on every ball, synthesized Web Audio effects, sparkle particles, and full 2-player rules.

## ✨ Features

- 🎱 **Unique Kawaii Faces** — Every ball has its own cute animated face (sparkle eyes, wink, :3 cat mouth, tongue, happy blinks)
- 😎 **Cool 8-Ball** — The 8-ball wears tiny sunglasses
- 😊 **Blush Cheeks & Squish Physics** — Balls deform and squish on impact
- 🔊 **Procedural Web Audio SFX** — Wooden cue hit, pitched ball clacks, cushion thuds, pocket chimes, and victory fanfare
- 💖 **Heart & Sparkle Particles** — Bursts of hearts on pockets and starry sparkles on collision
- 👥 **2-Player Mode** — Full 8-ball rules (solids vs stripes determined on first pocket)
- 🏆 **Win & Foul System** — Sink your category then pocket the 8-ball to win
- 🔄 **Play Again** button for instant rematch
- 📱 **Touch & Mouse** — Works smoothly on mobile, tablet, and desktop

## 🚀 Local Development

```bash
npm install
npm run dev
```

Then open `http://localhost:5174` in your browser.

## 🛠️ Tech Stack

- **Vite** — Fast modern build tool
- **HTML5 Canvas 2D** — Top-down rendering
- **Custom Physics Engine** — Realistic elastic momentum transfer, friction, and cushion restitution
- **Web Audio API** — Synthesized procedural audio
